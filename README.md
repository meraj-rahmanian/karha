# کارها

وب‌سایت نمونهٔ یک شرکت برنامه‌نویسی ایرانی — ساخته‌شده با **React** و **Vite** و **Tailwind CSS**.

> این پروژه یک **تمرین آموزشی** است؛ تکلیف درسی برای ساخت یک وب‌سایت شرکتی ساده با React. طرح (دیزاین) سایت را هوش مصنوعی در اختیار من گذاشته و ایدهٔ آن از ظاهر و ساختار وب‌سایت شرکت‌های برنامه‌نویسی ایرانی الهام گرفته شده است.
>
> تکلیف: ۲۳ آبان ۱۴۰۵ — تکمیل: ۱ آذر ۱۴۰۵ (۸ روز).

## فناوری‌ها

| فناوری | نسخه | کاربرد |
| --- | --- | --- |
| React | ۱۹ | رابط کاربری و کامپوننت‌ها |
| Vite | ۸ | بیلد و سرور توسعه |
| React Router | ۷ | مسیریابی بین ۵ صفحه |
| Tailwind CSS | ۴ | استایل‌دهی |
| ESLint | ۱۰ | بررسی کیفیت کد |

## صفحات

| صفحه | مسیر | محتوا |
| --- | --- | --- |
| خانه | `/` | هیرو، آمار، خدمات، نمونه‌کارهای منتخب، مراحل کار، نظر مشتری، دعوت به تماس |
| خدمات | `/services` | فهرست خدمات، جدول مقایسهٔ بسته‌ها، پرسش‌های پرتکرار (آکاردئون) |
| نمونه‌کارها | `/works` | فیلتر دسته‌بندی: همه، وبسایت، فروشگاه، اپلیکیشن |
| درباره ما | `/about` | داستان شرکت، ارزش‌ها، اعضای تیم، خط زمانی |
| تماس | `/contact` | فرم تماس و اطلاعات تماس |

## ویژگی‌ها

- **هدر چسبان** با مشخص‌شدن لینک صفحهٔ فعال و **فوتر** مشترک در همهٔ صفحه‌ها
- **منوی همبرگری** در موبایل و تبلت
- **ریسپانسیو کامل:** موبایل (کمتر از ۶۴۰ پیکسل)، تبلت (۶۴۰ تا ۱۰۲۴)، دسکتاپ (بیشتر از ۱۰۲۴)
- **راست‌چین کامل** (`dir="rtl"`) با اعداد فارسی
- سبک طراحی خط‌محور و تیز، تیترهای درشت، فقط دو رنگ لهجه (سرخ و خردلی)

## اجرا

```bash
npm install
npm run dev
```

| دستور | کار |
| --- | --- |
| `npm run dev` | اجرای سرور توسعه |
| `npm run build` | ساخت نسخهٔ نهایی |
| `npm run preview` | پیش‌نمایش نسخهٔ نهایی |
| `npm run lint` | بررسی کد با ESLint |
